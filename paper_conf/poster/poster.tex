% ---------------------------------------------------------------------
%  COLUMN 1 -- Question, the measure, setup
% ---------------------------------------------------------------------
\begin{column}{0.32\linewidth}

\begin{block}{1.~The Question}
Real corpora contain contradictions: the same problem appears with a correct
and an incorrect solution. Which one does a transformer trained from scratch
put its probability on, when frequency, format and domain are held equal?
Minimizing cross-entropy minimizes code length (Shannon 1948; Del\'etang et al.\
2024), which suggests an error the model cannot predict from the problem is
harder to accommodate than one it can. \textbf{We use this as motivation
only}; both experiments built to make it a measured mechanism turned out to
measure something else.
\end{block}

\begin{block}{2.~Measure the Whole False Side}
The usual metric is pairwise: does the correct completion beat \emph{one}
incorrect one? If the error can take $N$ forms, a model that merely reproduces
training frequencies puts $0.5$ on the correct string and $0.5/N$ on each
false one, and wins every pairwise comparison for $N \ge 2$.\\[0.3ex]
We sum over every string the generator can produce instead:
\[
  \text{share} = \frac{P(\text{correct})}{P(\text{correct}) + \sum_i P(\text{false}_i)}
\]
Each problem occurs exactly twice in the primary corpus (once correct, once
corrupted) and every other member of the family occurs zero times, so a
frequency-matching model scores \textbf{exactly $0.500$} for any $N$.
Adding strings can only lower the share: a value above $0.5$ is a lower bound.
Full-string log-probability, not a per-token mean; a length-matched subset
removes the remaining channel. Pair accuracy is reported only for comparability.
\end{block}

\begin{block}{3.~Experimental Design}
GPT-2-like decoder-only transformers trained \emph{from scratch}
(3.5M--86M, 4 seeds), Qwen3-architecture models at 418M--3.08B (2--4 seeds).
AdamW, lr\,$=3{\cdot}10^{-4}$, 5{,}000 steps, character tokenizer.
Four problem families (multi-step arithmetic, factoring, equation solving,
differentiation) rendered as step-by-step derivations and verified with SymPy;
only the \emph{structure of the errors} varies: random per problem, one
coherent false rule, $N$ competing rules, a rule with $L$ stored constants,
or a false family whose selector the model can or cannot learn.
Transfer: Wikipedia paragraphs with random or coherent entity substitution,
and a 490M model on 1\,GB of FineWeb-Edu with 8\,\% contradictory math.
More than 500 training runs; per-run outputs released.
\end{block}

\end{column}

% ---------------------------------------------------------------------
%  COLUMN 2 -- Central results
% ---------------------------------------------------------------------
\begin{column}{0.36\linewidth}

\begin{block}{4.~Central Contrast, and What the Pairwise Metric Adds}
\centering
\includegraphics[width=0.98\linewidth]{figure_mass_control.png}\\[0.3ex]
\justifying\normalsize
\textbf{Left:} denoising corpus, training problems, 4 seeds. Pair accuracy
reads $72$--$89\%$ at every size. Summing the generator's full support
leaves an effect only at 86M: $59.0 \pm 0.8\%$ (every per-seed bootstrap
interval above $0.5$; $59.4\%$ on an independent corpus). At 86M the
realized-error score adds $27.6$\,pp of excess above chance and pair accuracy
$37.4$\,pp where the family share gives $9.0$\,pp. The coherent rule sits at
$43.5$--$48.8\%$; the shortfall is completion length ($-0.58$ tokens), not a
preference.\\
\textbf{Right:} the description-length ladder (a single false rule storing
$L$ constants). Against the one realized false string the share rises with
$L$; against the full family it is flat at 86M ($55.6$, $51.9$, $52.6$,
$51.3$). \textbf{No grading in description length.}
\end{block}

\begin{block}{5.~Two Results We Withdraw}
\justifying\normalsize
\textbf{Multi-rule.} With $N$ competing false rules, pair accuracy jumps
$47 \to 79\%$ at $N{=}1 \to 2$ and reaches $90\%$ at $N{=}10$. On the same
checkpoints the aggregate share reads $47.9 \to 47.8 \to 38.7$: the jump is
\emph{mass splitting}, not a selector cost. Reported as a calibration of how
much pairwise signal splitting alone can manufacture.\\[0.3ex]
\textbf{Description-length ladder.} Built to show a graded effect; the family
measure is flat. A clean corpus with no false rule reads $99.7\%$ at 86M and
$64.1\%$ at 3.5M on the same support, so the measure is near-unbiased where
we report an effect and conservative where we report none.\\[0.3ex]
Compression remains an \emph{interpretation} of the surviving contrast, not a
quantity these experiments measure.
\end{block}

\end{column}

% ---------------------------------------------------------------------
%  COLUMN 3 -- The learnable-selector control, transfer, takeaway
% ---------------------------------------------------------------------
\begin{column}{0.32\linewidth}

\begin{block}{6.~What Moves the Preference: Learnability}
\centering
\includegraphics[width=0.98\linewidth]{figure_poster_learnable.png}\\[0.3ex]
\justifying\normalsize
Held-out grid, no problem seen twice, family share on the length-matched
subset, null $50$. The false answer is $a{\cdot}b + T[s(p) \bmod 10]$ for one
10-entry table; only the selector $s(p)$ changes. Unpredictable selector:
the correct system holds $+5$ points. Selector the model can learn (a visible
digit): the correct share falls to $43.4 \pm 0.6\%$ at 474M (4 seeds), and the
model prefers the \emph{false} system. Partly learnable selectors (sums of two
or three digits) sit at the null. Random and learnable share identical correct
derivations, so competence is matched and the selector is the only variable.
The contrast holds at 1.12B, 2.16B and 3.08B; a clean corpus reads
$96$--$99\%$ at every size.
\end{block}

\begin{block}{7.~Transfer and Noise}
\justifying\normalsize
\textbf{Wikipedia entity substitution} (3.5M--86M, 4 seeds, pair accuracy): a
coherent global mapping (``France''$\to$``Japan'') reads $46$--$49\%$ against
a $50\%$ null; a consistent substitution is not filtered on real text either.
The random column ($70$--$71\%$) has an unenumerable support and a null near
$100\%$, and is not interpreted. \textbf{490M on FineWeb-Edu} with 8\,\%
contradictory math: coherent $47.4 \pm 0.7\%$, not filtered (2 seeds).\\[0.3ex]
\textbf{Noise ratio} on the controlled measure (86M, 2 seeds): with $K$
random errors per problem the null is $1/(K{+}1)$; the share reads $56.3$,
$44.9$, $36.1$ at $K{=}1, 2, 4$ against $50.0$, $33.3$, $20.0$. The excess
above the null does not shrink with noise.
\end{block}

\end{column}
